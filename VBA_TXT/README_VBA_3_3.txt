AudioModem 3.3 Universal File Transfer

Что изменено:
- любые типы файлов; архивировать предварительно не требуется;
- имя файла передаётся отдельным FILEINFO кадром;
- файл читается/пишется блоками по 1024 байта;
- CRC32 каждого DATA-пакета и всего файла;
- поддержка восстановления исходного имени;
- модуль не загружает весь файл в память.

Ограничение этой совместимой VBA-редакции: до 2 ГБ на файл.

Важно:
Это прикладной уровень 3.3. Для реальной передачи звуком подключите PHY-код
модуляции/демодуляции из 3.2 к функциям AM33_BuildFileInfoFrame и
AM33_BuildDataFrame. После приёма DATA вызывайте AM33_WritePacket, затем
AM33_VerifyCompletedFile.
